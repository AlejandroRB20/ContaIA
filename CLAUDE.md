## Reglas obligatorias para Claude Code

1. Lee `MASTER_CONTEXT.md` antes de comenzar a trabajar en cualquier tarea.
2. Lee el PRD (`docs/01_PRD.md`) y la documentación relacionada con la tarea antes de actuar.
3. Presenta un plan y espera autorización antes de realizar cambios importantes.
4. No modifiques archivos que no estén relacionados con la tarea solicitada.
5. No inventes requisitos, funcionalidades ni alcances que no hayan sido indicados.
6. No uses información fiscal, contable o legal que no provenga de una fuente validada por el usuario.
7. Ejecuta las pruebas correspondientes después de programar cualquier cambio.
8. Informa siempre qué archivos fueron creados o modificados al finalizar una tarea.
9. Pide autorización explícita antes de realizar acciones destructivas (eliminar, sobrescribir, reiniciar).
10. Mantén el código y la documentación en español, excepto nombres técnicos, variables y código fuente.
